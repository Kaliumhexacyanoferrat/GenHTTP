GenHTTP over HTTP/3

Served by the experimental HTTP/3 engine, with HTTP/3 framing and QPACK from Glyph3 and QUIC from System.Net.Quic.

The first load arrives over HTTP/1.1. The response carries an Alt-Svc header pointing at the same port over UDP, so a reload should switch to HTTP/3. Check the Protocol column in the network tab.

Several subresources on purpose: repeated requests on one connection are what a QPACK dynamic table would compress.
